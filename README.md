# Chen En-Yu — Portfolio

Personal portfolio site. Static HTML/CSS/JS, no build step.

```
index.html        page shell
css/style.css     visual system + animation
js/data.js        generated project data (bilingual)
js/app.js         rendering, filters, lightbox, i18n
assets/img/       stills (web-sized)
assets/video/     compressed showreel videos
assets/poster/    video poster frames
```

Preview locally: `python -m http.server 8777`
